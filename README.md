# AI3連単（Project-012）

ボートレースの3連単予想ゲームです。

## 遊び方
1. ボートレース場を選択する
2. STARTボタンを押す
3. ルーレットが回り、3着→2着→1着の順に結果が決定される

## データについて
- データ出典: 艇国DB
- 集計期間: 2025年8月1日～2026年7月31日
- このゲームにおける「コース＝艇番」はゲーム上の簡易モデルであり、実際のレース予想を保証するものではありません。

## 開発環境
- Project-002のmain（`ace9acecda5c434039c6ffe09eae1fc159f22d65`）をコピーした独立プロジェクトです。

## スマートフォン表示
- 画面幅に応じて文字・選択欄・リールを伸縮させ、確定結果も画面幅の変更に追従します。
- 背景には同じ構図・解像度のWebP画像（約315KB）を使用します。元のPNG画像も保持しています。
- 3着→2着→1着の停止順と待ち時間は、マークシートの記入と演出を考慮した仕様です。
- 着順の説明や重複した結果表示は加えず、競艇に慣れた利用者向けの簡潔な画面を維持します。
- レース情報APIとの連携と、ユーザー・AIタカシのコメント欄は将来の構想で、未実装です。
