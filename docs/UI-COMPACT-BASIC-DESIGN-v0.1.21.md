# UIコンパクト化 基本設計書 v0.1.21

作成: 2026-10-01 JST。状態: コンパクト化とタイトル画像の独立配置を実装済み。Edge 6画面幅で表示試験済み。

関連: [詳細設計](UI-COMPACT-DETAILED-DESIGN-v0.1.21.md) / [試験仕様](UI-COMPACT-TEST-SPEC-v0.1.21.md) / [試験成績](UI-COMPACT-TEST-REPORT-v0.1.21.md)

## 1. 採用案

利用者が最後に選択した「変更案（買い目サイズ維持）」を採用する。375×667 CSS pxの比較画像を基準とする。過去に提示した買い目70px角への縮小案は採用しない。

本命の買い目の正方形・数字・色・間隔と、白枠の幅を維持し、上部の余白、本命パネル内の縦余白、STARTボタンを小さくする。v0.1.20の画面上の表示を削除する。画面全体の拡大率は変えない。

## 2. 対象範囲

- ページ上端、タイトル下、選択欄下、本命パネル内、レース展開欄とコメント欄の間の縦余白。
- STARTの幅・高さ・文字サイズ・角丸。本命ラベルの高さと下余白。
- 本命パネル右下のバージョン表示。
- 解析中はボタン内に「解析中…」を表示し、失敗・締切時だけボタン下にメッセージを表示する。

会場・レースの選択方式、締切表示、予想生成、AIへの指示、買い目・展開文、コメント機能、DB/APIの仕様は既存どおり。幅の調整はSTARTボタンのみとする。買い目は各画面幅で現在と同じサイズを維持する。

## 3. 現状実測と最新案の寸法（375×667）

Microsoft Edgeのローカル表示で、同一の会場・レース・買い目・文章を使用して比較。単位はCSS px、小数第2位まで。現在UIと実装後の画面を同一条件で表示し、寸法を比較した。単位はCSS px、小数第2位まで。

| 項目 | 現状 | 採用案 |
|---|---:|---:|
| ページ上端からタイトルまで | 52.02 | 13.00 |
| タイトルアイコン | 64×64 | 64×64 |
| 選択欄 | 220×46 | 220×46 |
| 本命白枠の幅 | 331.00 | 331.00 |
| 本命白枠の高さ（通常・解析中・成功） | 252.77 | 186.56（実測） |
| 本命買い目1個 | 84.375×84.375 | 84.375×84.375 |
| START | 187.52×44.39 | 169.94×36.00 |
| START下の空の状態表示欄の高さ | 24.00 | 0 |
| レース展開欄の上端 | 562.78 | 443.56（実測） |
| コメント欄の上端 | 745.78 | 592.56（実測） |

通常・解析中・成功時は、本命白枠を現状比で約66.20px縮める。レース展開欄は119.22px、コメント欄は153.22px上へ移動した実測値。失敗・締切時はメッセージの行数に応じて白枠が広がる。文章量や画面サイズで欄の位置は変化する。この設計は「画面の1/3に全要素を収める」ことを合格条件にしない。

## 4. バージョンと状態表示欄

v0.1.20は絶対配置のため、文字を消すだけでは白枠の高さは縮まらない。白枠の下paddingを16pxから4pxに変更して下端を上げる。

START押下から処理と結果表示が終わるまで、ボタンを「解析中…」にして無効化する。通常・解析中・成功時にボタン下の空行は確保しない。終了時は「START」に戻し、押せるかどうかは既存の締切・選択状態に従う。

失敗・締切のメッセージは従来と同じボタン直下の状態欄へ表示する。長い文は折り返し、白枠を内容に合わせて広げる。再試行を開始するとメッセージを消し、再びコンパクトな高さに戻る。解析中の読み上げ通知は画面外の状態欄で維持する。

## 5. 画面幅への対応

縦余白とSTARTの変更は全画面幅に適用する。既存の320px付近の内側余白、768px以上の80pxアイコン、最大480pxのコンテンツ幅、買い目の可変サイズを維持する。375×667を主基準とし、320/390/430/768/1280px幅でも幅の維持とはみ出しを確認する。

STARTの高さ36pxは採用画像と同じ。現在より押せる面積が小さくなるため、実装後にタッチ操作とキーボードフォーカスを確認する。

## 7. 追加設計：タイトル画像と文字の分離

利用者が承認した比較サンプルの右案を採用する。透過PNGのAIタカシ画像をタイトル見出しの左上へ独立して置き、タイトル文字は画面幅の中央に配置する。画像を丸く切り抜かず、画像全体を透過状態で表示する。見出し文字の中央位置は画像サイズに依存させない。

画像は左側の装飾要素として見出し上部に重ねる。タイトル文字と会場・レース選択欄に重ならないよう、見出し領域の高さを確保する。375px幅で現行より約20px選択欄が下がる比較サンプルを基準とする。320px幅では画像を小さくし、左端での切れと文字との重なりを防ぐ。サイト最大幅が480pxのデスクトップでも、画像はコンテンツ領域左上、タイトル文字は画面中央に保つ。

この変更で画像の見える領域とタイトル周辺の高さは増える。背景・白枠・買い目・予想ロジック・選択仕様は変更しない。320/375/390/430/768/1280px幅でタイトルの中央位置、画像と文字・選択欄の非重複、横はみ出しがないことをEdgeとChromeで確認済み。Firefox自動試験とWebKit実機の確認は未実施。
