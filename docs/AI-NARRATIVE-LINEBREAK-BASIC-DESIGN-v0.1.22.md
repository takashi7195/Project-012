# レース展開文の改行指示 基本設計書 v0.1.22

作成日: 2026-10-02 JST

## 目的

スマートフォン等でレース展開文を読みやすくするため、生成AIに改行位置を任せる。

## 採用仕様

- AIバンドル方式の基本指示へ「読みやすい位置で改行してください。」の一文だけを追加する。
- 段落数、改行回数、改行位置は固定しない。改行がない場合も形式エラーにしない。
- 既存の500文字前後という目安、事実根拠、JSON形式、買い目との整合条件は変更しない。
- 出力文字数の検証を追加しない。

## 影響

改行で表示欄が縦に長くなる場合がある。改行自体で文章を短くする処理はない。生成設定の出力トークン上限と90秒の生成期限は従来どおり。
