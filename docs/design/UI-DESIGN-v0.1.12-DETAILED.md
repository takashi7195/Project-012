# v0.1.12 UI詳細設計

## 対象

対象はスマートフォン向けの表示UIのみとする。3連単の予想計算、API、Gemini、Supabaseの処理は変更しない。基準画像は941×1672pxで作成されているため、CSS上の基準幅390pxへ約0.414倍で正規化する。

- 基準幅: 390px
- 画像の基準比率: 941:1672
- 小型幅: 320px
- 中間幅: 360px
- 大型幅: 430px
- タブレット以上: 768px以上

画像上の座標は見た目の比率を合わせるための基準として使用し、実装では固定座標ではなく`max-width`、`clamp()`、`aspect-ratio`、`gap`で再現する。

## 共通ビジュアル

- 背景は`boat-bg-v2.webp`を画面固定で全面表示し、`center / cover`を使う。
- 背景の上に白〜水色の半透明パネルを置く。
- パネルの標準色は`rgba(237,247,255,.78)`、境界線は`rgba(255,255,255,.9)`、角丸は14〜18px、影は`0 6px 22px rgba(0,28,58,.14)`。
- 主文字は濃紺系（#102a56〜#172a3c）、補助文字は#536171、操作ボタンは#1677ee。
- 横スクロールを禁止し、左右の安全余白を最低12px確保する。

## 3. コメント入力画面

- 「コメントを書く」を押すと、背景を`rgba(4,27,51,.45)`で暗くし、下部シートを表示する。
- シートは画面下端に固定し、上端の角丸18px、幅は`min(640px, calc(100% - 16px))`。
- シート上端に高さ4px程度のドラッグハンドルを置く。
- ヘッダーは左に「コメントを書く」（20px太字）、右に円形の閉じる×ボタン（40px）を配置する。
- ニックネーム欄は高さ46px、角丸7px、16px文字、プレースホルダー「ニックネーム（任意）」。
- 本文欄は最低76px、高さは入力に合わせて最大150pxまで拡張し、プレースホルダー「レースの感想をどうぞ」。
- 利用案内は12px、文字数は右寄せ12pxで`0/300`形式。入力上限300文字を維持する。
- 送信ボタンは高さ46px、幅は最大180px、右寄せ、青#1677ee、角丸12px、白文字16px・太字。
- キーボード表示中は`visualViewport`に追従し、送信ボタンがキーボードに隠れないようにする。入力時にページ全体をスクロールさせない。
- 送信中はボタンを一時無効化し、成功時は入力シートを閉じて投稿完了通知を表示する。失敗時はシートを閉じず、入力内容を保持する。

## レスポンシブ規則

- 320pxではタイトルを22〜24px、ルーレット枠を64px程度まで縮小する。
- 360〜390pxでは基準値を使う。
- 430pxではパネルの最大幅を640px以内に保ち、枠とカードを引き伸ばしすぎない。
- 768px以上ではコンテンツ幅を640px以内に固定し、背景だけを画面全体に広げる。
- すべての操作部品はタップ領域44px以上を確保する。

## 検証項目

1. 320/360/390/430pxで横スクロールが発生しない。
2. タイトル、選択欄、ルーレット、対抗・穴、レース展開の順序と余白が基準画像に近い。
3. コメントカードのユーザーアイコン、AIアイコン、OFUSEリンクが崩れない。
4. コメント入力シートを開いた状態で、iOS SafariとAndroid Chromeのキーボードに送信ボタンが隠れない。
5. 入力欄の自動伸縮、300文字制限、送信成功・失敗時の状態を維持する。

## v0.1.13 予想文章の選手名表記

- レース展開では、取得できた選手の姓・名を含むフルネームを使用する。
- ニックネーム、省略名、姓だけの表記には変更しない。

## v0.1.13 総合点の欠損データ処理

- 各艇の最終点は、`取得済み得点 ÷ 取得済み項目の満点合計 × 100`で算出する。
- 全国共通基準の項目は、取得できた艇について得点化する。未取得の艇はその項目を除外して再換算する。
- レース内6艇の相対評価項目は、6艇分のデータがすべて揃っている場合だけ評価する。
- 相対評価項目が1艇でも欠けている場合、その項目は6艇すべての総合点から除外する。
- 欠損項目を0点として扱わない。

## v0.1.13 同点時の優先順位

総合点が同点の場合は、次の順で比較する。総合点は表示丸め前の内部値を使用する。

1. 総合点の小数点以下を含む内部値
2. 直前展示（展示タイム）
3. 展示スタート（展示ST）
4. 平均ST
5. モーター成績
6. 枠番が小さい艇

全項目が完全に同じ場合は、艇番の小さい順で安定的に決定する。

## v0.1.13 相対評価の順位配点

レース内相対評価項目は、6艇の順位を次の割合で点数化する。値はコードに直書きせず、設定値として後から調整できるようにする。

| 順位 | 配点割合 |
|---:|---:|
| 1位 | 100% |
| 2位 | 80% |
| 3位 | 60% |
| 4位 | 40% |
| 5位 | 20% |
| 6位 | 0% |

項目の満点にこの割合を掛けて、その項目の得点を算出する。欠損がある場合は、既定の欠損処理に従い項目全体を除外する。

## v0.1.13 全国成績・当地成績の合成

初期実装では、勝率を設定可能な段階式テーブルで0〜100点化した後、次の比率で合成する。

```text
全国勝率：60%
当地勝率：40%
```

当地勝率は水面適性を反映するが、出走数が少ない場合のブレを考慮し、全国勝率を重くする。当地出走数による信頼度補正は後の調整課題とする。

## v0.1.13 連対率の着順別分解

1着率・2連対率・3連対率は重複を避けるため、次のように分解してから合成する。

```text
1着率 = 1着率
2着率 = 2連対率 - 1着率
3着率 = 3連対率 - 2連対率
```

分解後の重みは次のとおりとする。

```text
1着率：50%
2着率：30%
3着率：20%
```

APIの丸め誤差などで差分が負になる場合は0に補正し、使用可能な値を再正規化する。

## v0.1.13 モーター性能の分解

モーター2連対率と3連対率の重複を避けるため、次のように分解する。

```text
モーター2連対率 = モーター2連対率
モーター3着追加率 = モーター3連対率 - モーター2連対率
```

分解後の重みは次のとおりとする。

```text
モーター2連対率：70%
モーター3着追加率：30%
```

6艇すべてのデータが揃う場合に相対評価し、モーター項目の14点へ変換する。差分が負になる場合は0補正する。「現在の気配」は展示タイム・展示ST・チルト側で評価し、モーター項目と二重に加点しない。

## v0.1.13 STと直前展示の役割分担

ST項目12点は、展示STを含めず、次の配分とする。

```text
平均ST：80%
フライング・出遅れ：20%
```

平均STは選手本来のスタート能力、フライング・出遅れは信頼性の補正として扱う。展示STは「直前展示」項目で展示タイム・チルトと合わせて評価し、二重加点しない。

## v0.1.13 直前展示の配分とチルト補正

直前展示12点は次の配分とする。

```text
展示タイム：55%
展示ST：40%
チルト：5%
```

展示タイムと展示STは6艇内で相対評価する。チルトは大きさだけで順位付けせず、会場・進入・展示タイムとの関係を考慮する補助的な設定値として加点・減点する。チルト単独で高評価・低評価を決めない。

## v0.1.13 レース場特性・風・波の評価

「レース場特性・風・波」7点は、次の内訳で評価する。

```text
会場特性補正：4点
風向・風速：2点
波高：1点
```

会場特性補正は、進入コースそのものの有利不利を再評価せず、各会場のコース別入着傾向が全国平均からどれだけ離れているかを補正する。これにより「進入コース・枠番」18点との二重評価を避ける。

風向・風速は、各艇の進入コースとの相性を設定値で補正し、波高は荒れ水面による影響を小さく補正する。いずれもGeminiに順位を決めさせず、バックエンドの設定可能なルールで計算する。

風向・風速または波高が取得できない場合は、欠けた部分だけを評価対象から除外し、残った満点で再換算する。

## v0.1.13 今節成績の評価

今節成績4点は、まず今節得点率を使用し、得点率が取得できない場合だけ平均着順を代替値とする。得点率は着順だけでなく失格・減点なども反映しやすいため、平均着順より優先する。

6艇すべてに同じ指標が揃っている場合、6艇内で相対順位を付け、既定の順位配点（100%、80%、60%、40%、20%、0%）を4点へ変換する。得点率・平均着順のどちらも揃わない場合、または相対評価に必要な6艇分が揃わない場合は、この4点全体を除外して再換算する。使用した指標と取得時刻は予想入力とともに保存する。

## v0.1.13 ボート性能の分解

ボート成績2点は、モーター成績と同じ考え方で重複を避ける。

```text
ボート2連対率：70%
ボート3着追加率（ボート3連対率 − ボート2連対率）：30%
```

分解後の値を6艇内で相対評価し、既定の順位配点（100%、80%、60%、40%、20%、0%）を2点へ変換する。1艇でも必要な値が欠ける場合は、ボート成績2点全体を評価対象から除外して再換算する。差分が負になる場合は0に補正する。

## v0.1.13 選手の実力・近況の評価

選手の実力・近況9点は、全国成績やコース別成績との重複を避け、直近成績に限定する。初期対象は直近10走とし、対象走数・対象期間は設定値として変更可能にする。

```text
直近3連対率：60%
直近平均着順：40%
```

各指標を全国共通の段階式基準で0〜100点化し、9点へ変換する。片方が未取得の場合は取得できた指標だけで9点を再換算する。今節成績とコース別成績は別項目として扱う。

## v0.1.13 進入コース・枠番の評価

進入コースと枠番の重複評価を避けるため、18点は次の排他的な方式で評価する。

```text
進入コース取得あり：進入コースだけで18点評価
進入コース未取得：枠番を代理として18点評価
```

両方を同時に加点しない。進入コースも枠番も取得できない場合は、この18点を除外して再換算する。進入コースの基準は全国共通の設定可能な段階式とし、枠番を代理に使う場合も同じ18点の枠で評価する。

## v0.1.13 選手のコース別成績の評価

選手のコース別成績16点は、初期実装では全国共通基準100%で評価し、レース内相対評価は行わない。6艇間の最終比較は総合点で行う。

実際の進入コースを優先し、取得できない場合だけ枠番を代理にする。1着率・2連対率・3連対率は次のように着順別へ分解し、1着率50%、2着率30%、3着率20%で合成する。

```text
1着率 = 1着率
2着率 = 2連対率 − 1着率
3着率 = 3連対率 − 2連対率
```

合成値を全国共通の段階式基準で0〜100点化し、16点へ変換する。進入コースと枠番の両方が不明な場合は16点を除外して再換算する。将来のバックテスト結果に応じて、全国基準とレース内相対評価のハイブリッド方式を追加検討する。

## v0.1.13 体重・部品交換の補助評価

「体重・チルト・部品交換など」1点では、チルトを評価しない。チルトは直前展示12点の5%でのみ扱い、二重加点を避ける。

```text
体重・調整体重：0.6点
部品交換・整備情報：0.4点
```

体重は単純に軽いほど高評価とせず、調整体重を中心に会場・艇・展示状況を踏まえた小さな補助補正とする。部品交換・整備情報は、交換したこと自体を一律に加点・減点せず、補助情報として小さく補正する。各項目が未取得の場合は、その部分だけを除外して再換算する。

全国勝率60%、当地勝率40%で合成する。当地勝率は対象場での適性を表す別指標として扱う。基準値と配分は設定変更可能とする。

## v0.1.13 総合点から順位を決める計算手順

予想生成時点で取得可能な最新データを6艇分取得し、各評価項目を0〜100点化して項目配点へ変換する。項目内の配分を適用した後、次の式で最終点を求める。

```text
最終点 = 取得済み項目の得点合計 ÷ 取得済み項目の満点合計 × 100
```

全国共通項目は取得できた項目だけで再換算し、6艇内相対評価項目は6艇すべてのデータが揃わない場合に項目全体を除外する。最終点は表示丸め前の内部値を保持して順位付けする。

最終点の内部値が完全一致した場合だけ、次の順で同点処理を行う。

```text
1. 直前展示
2. 展示ST
3. 平均ST
4. モーター成績
5. 枠番が小さい艇
```

最後まで同じ場合も枠番の小さい艇を上位とする。予想スナップショットには、計算根拠、除外項目、各項目の点数、使用データ、取得時刻を保存する。

## v0.1.13 本命・対抗の3連単構成

総合点で全艇を順位付けし、次の順序で本命と対抗を生成する。

```text
本命：総合1位 → 総合2位 → 総合3位
対抗：総合2位 → 総合1位 → 総合4位
```

Geminiには組み合わせを選ばせず、バックエンドの順位結果から決定する。必要な順位の艇が不足する場合は、その予想を生成しない。

## v0.1.13 穴の3連単構成

オッズを使わないため、配当額そのものではなく上位評価を崩す可能性を穴として評価する。

1. 総合4〜6位を穴候補とする。
2. 候補の中から、展示タイム、展示ST、モーター成績、平均STの上振れ要素が最も強い艇を選ぶ。
3. 選んだ艇を1着にする。
4. 2着・3着は残りの総合点上位から選ぶ。

上振れ要素は既存の評価データを用い、オッズやGeminiの主観で選ばない。配当を直接予測する機能ではなく、総合順位外からの波乱候補を抽出する機能として扱う。

## v0.1.13 穴の上振れ判定

総合4〜6位の穴候補は、既存の評価点を次の配分で再評価する。

```text
展示タイム：30%
展示ST：30%
モーター成績：25%
平均ST：15%
```

最も高い候補を穴の1着艇とする。オッズを使わないため、穴は高配当を意味するものではなく、「総合評価は低いが上振れ材料がある艇」というシステム上の定義とする。新しい評価項目は追加せず、既存の計算済み評価点を使用する。
