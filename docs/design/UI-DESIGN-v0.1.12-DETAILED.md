# v0.1.12 UI詳細設計

## 対象

対象はスマートフォン向けの表示UIのみとする。3連単の予想計算、API、Gemini、Supabaseの処理は変更しない。基準画像は941×1672pxで作成されているため、CSS上の基準幅390pxへ約0.414倍で正規化する。

- 基準幅: 390px
- 画像の基準比率: 941:1672
- 小型幅: 320px
- 中間幅: 360px
- 大型幅: 430px
- タブレット以上: 768px以上

画像上の座標は見た目の比率を合わせるための基準として使用し、実装では固定座標ではなく`max-width`、`clamp()`、`aspect-ratio`、`gap`で再現する。

## 共通ビジュアル

- 背景は`boat-bg-v2.webp`を画面固定で全面表示し、`center / cover`を使う。
- 背景の上に白〜水色の半透明パネルを置く。
- パネルの標準色は`rgba(237,247,255,.78)`、境界線は`rgba(255,255,255,.9)`、角丸は14〜18px、影は`0 6px 22px rgba(0,28,58,.14)`。
- 主文字は濃紺系（#102a56〜#172a3c）、補助文字は#536171、操作ボタンは#1677ee。
- 横スクロールを禁止し、左右の安全余白を最低12px確保する。

## 1. ルーレット画面

390px換算の目安：

- ページ左右余白: 12〜16px
- タイトル上余白: 24px、タイトル下余白: 18px
- タイトル: 28px、700〜800、中央揃え、白文字＋薄い影
- 会場・レース選択: 高さ44px、角丸10px、左右8pxの間隔、白の不透明度90％
- ゲームパネル: 幅100％、内側余白14〜16px、角丸14px
- 本命ラベル: パネル左上、幅約66px、高さ31px、白い丸角枠、文字16px、`◎ 本命`
- ルーレット3枠: 1枠あたり64〜88px（幅に応じて可変）、間隔8px、角丸14px、境界線2px
- 艇色: 1号艇#EBEBEB＋黒文字、2号艇#505050＋白文字、3号艇#F04141＋白文字、4号艇#4184D0＋白文字
- 数字: 32〜44px、Arial系、太字、中央揃え
- START: 幅210px以下、画面幅の72％以下、高さ46px、青#1677ee、角丸12px、白文字20px・太字
- バージョン: 11px、右下、半透明の濃紺
- 下部の対抗・穴行: 高さ約42px、白半透明の横長カード、左に白枠ラベル、数字は艇色の小枠で表示
- レース展開カード: 対抗・穴の下に配置、上下16pxの余白、見出し20px、本文15〜16px、行間1.6

上部ルーレットが本命を表すため、下部には本命行を重複表示しない。

## 2. コメント一覧画面

- ルーレット画面の背景・タイトル階層・左右余白を共通化する。
- コメント見出し行は左右に分け、左に「コメント」、右に青い「コメントを書く」ボタンを置く。
- 見出しカードは白半透明、角丸14px、内側余白12〜14px。
- 「コメントを書く」ボタンは高さ42px、幅は内容に合わせ、角丸999px、青背景、白文字15px・太字。
- コメントカードは白半透明、角丸12〜14px、上下14pxの間隔、内側15〜16px。
- ユーザーアイコンは40pxの円形。ニックネームの先頭1文字を表示し、匿名は「匿」。背景色はニックネームから決定する既存のパレットを維持する。
- ユーザー名は15〜16px太字、投稿時刻は12pxで同じ行に表示する。
- ユーザー本文は15px、行間1.65、濃紺で表示する。
- AI返信は左側の青いアクセント線を維持し、AIタカシアイコンは40pxの円形画像。AI返信には時刻を表示しない。
- OFUSEリンクは返信の下に必要な場合だけ表示し、`🍺 タカシに生ビールをおごる`の文言と既存のリンク動作を維持する。
- コメント一覧が長くなってもページ全体の背景は固定し、コメントカードが下方向へ続く構成にする。

## 3. コメント入力画面

- 「コメントを書く」を押すと、背景を`rgba(4,27,51,.45)`で暗くし、下部シートを表示する。
- シートは画面下端に固定し、上端の角丸18px、幅は`min(640px, calc(100% - 16px))`。
- シート上端に高さ4px程度のドラッグハンドルを置く。
- ヘッダーは左に「コメントを書く」（20px太字）、右に円形の閉じる×ボタン（40px）を配置する。
- ニックネーム欄は高さ46px、角丸7px、16px文字、プレースホルダー「ニックネーム（任意）」。
- 本文欄は最低76px、高さは入力に合わせて最大150pxまで拡張し、プレースホルダー「レースの感想をどうぞ」。
- 利用案内は12px、文字数は右寄せ12pxで`0/300`形式。入力上限300文字を維持する。
- 送信ボタンは高さ46px、幅は最大180px、右寄せ、青#1677ee、角丸12px、白文字16px・太字。
- キーボード表示中は`visualViewport`に追従し、送信ボタンがキーボードに隠れないようにする。入力時にページ全体をスクロールさせない。
- 送信中はボタンを一時無効化し、成功時は入力シートを閉じて投稿完了通知を表示する。失敗時はシートを閉じず、入力内容を保持する。

## レスポンシブ規則

- 320pxではタイトルを22〜24px、ルーレット枠を64px程度まで縮小する。
- 360〜390pxでは基準値を使う。
- 430pxではパネルの最大幅を640px以内に保ち、枠とカードを引き伸ばしすぎない。
- 768px以上ではコンテンツ幅を640px以内に固定し、背景だけを画面全体に広げる。
- すべての操作部品はタップ領域44px以上を確保する。

## 検証項目

1. 320/360/390/430pxで横スクロールが発生しない。
2. タイトル、選択欄、ルーレット、対抗・穴、レース展開の順序と余白が基準画像に近い。
3. コメントカードのユーザーアイコン、AIアイコン、OFUSEリンクが崩れない。
4. コメント入力シートを開いた状態で、iOS SafariとAndroid Chromeのキーボードに送信ボタンが隠れない。
5. 入力欄の自動伸縮、300文字制限、送信成功・失敗時の状態を維持する。

## v0.1.13検討事項：会場・レース選択

- 会場プルダウンには、当日レースを開催している会場だけを表示する。
- 選択した会場の全レースをレースプルダウンに表示する。
- 締切済み・選択不可のレースはグレー表示にする。
- 締切前のレースだけ選択可能にする。
- 選択不可項目には内部的にHTMLの`disabled`属性を付ける。画面上に「disabled」などの説明文は表示しない。
- 選択可能なレースがない会場は会場一覧から除外する。
- 日付や開催状況の案内文は追加せず、DBの当日データと締切時刻から選択肢を自動生成する。
- API更新後に選択肢を再計算し、締切状態を最新化する。

## v0.1.13 予想文章の選手名表記

- レース展開では、取得できた選手の姓・名を含むフルネームを使用する。
- ニックネーム、省略名、姓だけの表記には変更しない。
- 選手名が取得できない場合だけ「1号艇」のような号艇表記を使う。
- DBにない戦法特性を、選手名と結び付けて推測・断定しない。

## v0.1.13 総合点の欠損データ処理

- 各艇の最終点は、`取得済み得点 ÷ 取得済み項目の満点合計 × 100`で算出する。
- 全国共通基準の項目は、取得できた艇について得点化する。未取得の艇はその項目を除外して再換算する。
- レース内6艇の相対評価項目は、6艇分のデータがすべて揃っている場合だけ評価する。
- 相対評価項目が1艇でも欠けている場合、その項目は6艇すべての総合点から除外する。
- 欠損項目を0点として扱わない。
