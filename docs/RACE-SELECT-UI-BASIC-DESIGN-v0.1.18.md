# v0.1.18 レース選択UI 基本設計書

作成日: 2026-09-25 JST
状態: 実装済み・幅調整反映
対象: 公開ページのレース選択プルダウン表示のみ

## 1. 背景

公開ページの操作確認で、レース選択肢に`11R | 20:08 締切予定`のように区切り記号`|`が表示され、閉じたプルダウンでは締切時刻が途中で切れて見えることを確認した。会場・レース選択ロジックや予想処理を変更せず、レース番号と締切情報を読み取りやすくする。

## 2. 目的

- レース選択肢から`|`をなくす。
- レース番号と締切表示の間に視認できる間隔を設ける。
- 選択欄でレース番号・締切時刻・状態ができるだけ切れずに読めるようにする。
- スマートフォンでも現在の横並びUIを保ち、画面幅に収める。

## 3. 表示仕様

選択可能なレースは、例として`11R　20:08 締切予定`と表示する。`R`の後は全角スペース1文字を使い、`|`は使わない。締切済みレースは`1R　締切`とする。レース番号は1Rから12Rの順序を維持し、締切済みレースも一覧に残す。

締切時刻は現行どおり取得済みの`closedAt`を日本時間で表示する。締切前後の判定、無効化、欠損・不正時刻のfail-closed動作は維持する。選択値、変更イベント、STARTの安全判定にも変更を加えない。

## 4. レイアウト方針

会場とレースの横並びと、従来の選択欄サイズ（幅64%、最小220px、最大280px）を維持し、2つの欄を均等幅で表示する。表示改善は区切り文字を全角スペースへ置き換えて行い、欄全体の幅や欄ごとの比率は変更しない。ネイティブ`select`の選択肢表示を維持する。

## 5. 対象外

- 会場の表示名、並び順、開催判定、選択可否
- 締切判定、対象日、JST変換、API取得頻度
- レース選択後の予想枠クリア、START有効条件、予想生成
- ルーレット、対抗・穴の表示タイミング
- Edge Function、DB、migration、Secrets

## 6. 完了条件

1. 表示例が`11R　20:08 締切予定`および`1R　締切`となり、`|`を含まない。
2. 1R〜12Rの順序と締切済みレースの表示・選択禁止が維持される。
3. 締切前は実際のJST締切時刻を表示し、締切表示を推測・固定しない。
4. デスクトップとスマートフォンで会場名、レース番号、締切表示が不自然に切れず、横はみ出しがない。
5. 会場選択、レース選択、STARTの既存動作に回帰がない。

## 7. 実装・検証方針

詳細設計書に従い、`script.js`のレース選択肢ラベルと`ui-reference.css`の選択欄レイアウトを中心に変更する。表示文言の単体テストと、既存の締切・選択制御テストを実行し、実機相当の狭い画面幅で表示を確認する。
