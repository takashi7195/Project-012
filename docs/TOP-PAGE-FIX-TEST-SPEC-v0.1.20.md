# トップページ表示調整 試験仕様書 v0.1.20

作成日: 2026-10-01 JST。実装後に実行する試験計画。

| ID | 試験 | 合格条件 |
|---|---|---|
| UI01 | 画像表示 | タイトル左に画像が読み込まれる。スマートフォン64px角、768px以上80px角。画像が歪まない |
| UI02 | 320/375/390/430/768/1280pxで見出しと選択欄を確認 | アイコンが縮まず、タイトル文字が欠けない。重なりと横スクロールがない |
| UI03 | レース選択と時刻表示 | select選択肢は9Rのみ。選択中は隣にJST時刻と締切予定を全文表示。9R/12R、00:00/18:52/23:59を含む |
| UI04 | 締切表示の同期 | 会場・レース変更、再取得、日付更新、締切で前の時刻が残らない。JSTの正しい時刻を表示 |
| UI05 | JavaScript実行前・無効・取得待ち・取得失敗 | 初期展開本文が空で、例文が一度も表示されない |
| UI06 | 生成と消去 | 成功時は生成本文、選択変更・失敗時は既存仕様どおり消去。買い目表示とSTART制御が正常 |
| UI07 | 操作と読み上げ | キーボード・タッチで選択可能。レースの読み上げから締切情報を確認できる。画像による名前の二重読み上げがない |
| UI08 | 公開反映（公開指示後） | 公開HTML/CSS/JSが対象版。再読み込みで更新内容を表示 |
| UI09 | 320/375/390/430/768/1280pxで白い枠を比較 | game-panelとcomments-sectionの外枠の幅・左右端が各1px以内で一致する。コメントあり・空状態・取得失敗でも本文や投稿ボタンがはみ出さない |

ローカルブラウザー試験では外部通信をモックする。既存のai-ui-browser-smoke.cjsと日付・締切の試験を変更範囲に応じて使用する。レース時刻がselectの外にあるため、狭幅でも時刻が欠けず、選択肢自体はレース番号だけであることを確認する。ページ全体に横スクロールがないだけでは合格にしない。ネイティブ一覧はWindows Edgeと実機スマートフォンで見え方を確認し、未確認の環境は明記する。
