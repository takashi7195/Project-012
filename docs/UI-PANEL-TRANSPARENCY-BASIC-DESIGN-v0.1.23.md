# UI白枠の透過率調整 基本設計書 v0.1.23

## 目的

画面内の白いパネル枠から背景を少し見せ、画面の一体感を高める。

## 変更方針

- ゲーム枠、会場・レース選択枠、対抗・大穴行、レース展開枠、コメント欄外枠とコメント見出しの背景不透明度を80%（透明度20%）にそろえる。
- 既存の淡い青色の色味とグラデーションは保つ。
- 文字、買い目、ボタン、入力欄、ラベル類の見え方は変更しない。
- 枠の幅・高さ・余白・配置および機能は変更しない。

## 対象外

コメント投稿シート、選択肢、操作ボタン、艇番タイル、ラベルなど操作部品の背景。

## 確認

基本の確認はCSS値の検査とローカルUI表示で行う。スマートフォンで背景と文字の見え方を最終確認する。
