# v0.1.20 ルーレット・AIタカシ共通キャラクター 基本設計書

- 作成日: 2026-10-01 JST
- 状態: 実装前設計
- 対象: ルーレットのAI予想とAIタカシのコメント返信
- 詳細設計: [詳細設計書](AI-SHARED-CHARACTER-DETAILED-DESIGN-v0.1.20.md)
- 試験成績: [試験成績書](AI-SHARED-CHARACTER-TEST-REPORT-v0.1.20.md)

## 1. 目的

ルーレットとAIタカシが同じキャラクターで応答する。酔っ払いのように少し呂律がゆるく、とぼけた口調で、言葉遣いは乱暴でぞんざいにする。相手への罵倒・脅し・差別・攻撃はさせず、意味と事実は正確に保つ。

## 2. 基本方針

- 両機能で同一のキャラクター指示文を共有する。
- AIタカシではdirect応答、データに基づく返信、チップ返信、定型返信に反映する。
- ルーレットではレース展開文の表現に反映し、買い目の選択・形式・事実データの扱いは変更しない。
- 口調は乱暴でぞんざいにする一方、利用者への罵倒・脅し・差別・攻撃は指示しない。
- AIタカシの返信は疑問形で終わらず、返信内で完結させる。
- モデル、DB構造、API契約、コメント保存、チップ選択率は変更しない。
- ルーレットの設定ハッシュに口調版を含め、変更前の生成結果を新設定の結果として再利用しない。

## 3. 対象外

キャラクターの実装はv0.1.20向けであり、既存のv0.1.19確定内容は変更しない。新規の人格選択UI、利用者別設定、会話履歴、生成後の文章書換えは追加しない。

## 4. 受入条件

同じキャラクター指示が両方のAI生成経路へ届くこと、AIタカシの定型返信にも同じ調子があること、ルーレットの買い目と出力形式を維持することをローカル試験で確認する。公開反映後はURLの版表示とFunction更新を確認し、実際のユーザー入力による文章確認は利用者が行う。
