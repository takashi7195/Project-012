# 本文可読性の統一 基本設計書 v0.1.22

作成日: 2026-10-02 JST。対象はライブページのレース展開本文、ユーザーコメント本文、AIタカシ返信本文。

## 目的

3種類の文章を同じ文字仕様にして、画面内で読みやすさを揃える。

## 採用仕様

- 既存のフォント候補順と端末側でのフォント選択を維持する。
- 3種類の本文を16px、太さ500、行の高さ1.6倍、文字色 `#172235`、上下余白0に統一する。
- レース展開とAI返信は`pre-line`、ユーザーコメントは`pre-wrap`とし、3種類すべてに`overflow-wrap:anywhere`を設定する。
- 見出し、投稿者名、投稿時刻、返信ラベル、ボタン、本文以外の余白・色、文章内容は変更しない。
- 変更はライブページのCSSに限定し、機能・API・DBに影響させない。

## 確認方法

ローカルWebブラウザで3種類の本文の計算済みスタイルを確認する。公開URLへの反映は本作業の対象外。
