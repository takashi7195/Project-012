# v0.1.18 会場開催状態の視認性 基本設計書

作成日: 2026-09-25 JST
状態: 実装前設計
対象: 会場プルダウン内で開催中会場と選択不可会場を見分けにくい課題のみ

## 1. 背景

会場プルダウンでは開催中の会場と選択不可の会場が表示されるが、通常表示とグレーアウトの差が小さく、一覧内で状態を見分けにくい。

## 2. 目的

既存の開催状態と選択可否を保ったまま、プルダウンを開いたときに開催中会場と選択不可会場を視覚的に識別しやすくする。

## 3. 基本方針

- 開催中会場は通常の文字色で表示する。
- 選択不可会場は文字色をグレーにして開催中会場との差を明確にする。背景色は現行のまま維持する。
- 視認性の調整は文字色だけで行い、文字の太さ（font-weight）は変更しない。
- すべての会場optionは会場名だけを表示し、開催状態の文言は追加しない。
- 会場の状態は既存の競艇データから算出した選択可否をそのまま使う。
- 選択不可会場の`disabled`状態を維持し、見た目だけで選択制御しない。

## 4. 変更範囲

会場プルダウンの選択肢における開催中・選択不可状態の視認性だけを調整する。対象は会場optionの既存状態に応じた表示であり、開催判定やデータ取得の処理は変更しない。

## 5. 明示的な対象外

- 選択欄全体・会場欄・レース欄の幅、比率、位置、余白
- 選択欄、option背景、行の色の濃さを含む他の画面要素
- 文字の太さ（font-weight）
- 会場名と表示順
- 開催判定、締切判定、`disabled`条件、更新頻度
- レース選択肢と締切表示
- ルーレット、本命・対抗・穴、START、予想ロジック
- DB、API、Edge Function、migration、Secrets

## 6. 完了条件

1. 開催中会場が通常の文字色で明瞭に読める。
2. 選択不可会場の文字色はグレーとなり、既存背景のまま開催中会場とひと目で区別できる。
3. 開催中・選択不可のどちらも会場名だけを表示し、状態文言を追加しない。
4. 選択不可会場は引き続き選択できない。
5. 幅、並び順、行間、周囲の色調など対象外の見た目・挙動に差分がない。

## 7. 追補：開催中ラベルの取り下げ

2026-10-02追補。開催中会場の末尾に追加した状態ラベルは見にくいとの確認を受け、ラベルを取り下げる。会場名だけの表示に戻し、既存の開催中・選択不可の文字色と`disabled`表示を維持する。開催判定と選択可否は変更しない。

## 8. 追補：開催中会場の太字表示試験

2026-10-02追補。iPhone 13 mini SafariとXperia Ace 3で確認するため、開催中optionだけに太字を指定するCSSを試験する。会場名、表示順、文字色、開催判定、選択可否は変えない。端末で改善が確認できない場合、この独立した試験変更を取り消して会場optionを通常の太さに戻す。
