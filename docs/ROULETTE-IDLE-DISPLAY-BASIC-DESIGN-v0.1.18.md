# v0.1.18 ルーレット待機表示 基本設計書

作成日: 2026-09-25 JST
状態: 実装前設計
対象: 会場・レース選択後に本命ルーレットが空欄になる課題のみ

## 1. 背景

会場またはレースを選択すると、本命ルーレットが空欄になる。選択直後から予想開始まで、ルーレットの表示が消えて操作画面が不安定に見える。

## 2. 目的

予想結果がまだない待機状態でも、本命ルーレットに初期数字「1・2・3」を表示する。数字はルーレットの待機表示であり、予想順位や買い目を表さない。

## 3. 表示仕様

- 初回表示時と会場・レース選択後の待機状態で、本命ルーレットに「1・2・3」を表示する。
- 表示は既存の3枠を使い、既存のルーレット表示部品を維持する。
- 初期数字は予想結果として扱わない。予想結果データ、API payload、順位、買い目には設定しない。
- START後は既存の予想取得・ルーレット演出を利用し、予想結果を受け取ってから確定数字を表示する。
- 会場・レース未選択中も初期表示を保ち、STARTの既存無効条件を維持する。

## 4. 変更範囲

本命ルーレットの空欄を待機用の「1・2・3」で置き換える表示状態だけを変更する。会場・レース選択、締切判定、取得中表示、対抗・穴・レース展開、予想ロジックには変更を加えない。

## 5. 明示的な対象外

- 会場・レース選択欄の幅、比率、位置、余白
- 色、濃さ、透明度、文字サイズ、フォント、角丸等の見た目
- 会場・レースのラベル、順序、開催状態、選択可否
- START制御、データ取得中の挙動、API呼び出し
- 対抗・穴・レース展開の表示タイミング
- 採点、本命・対抗・穴の計算
- DB、migration、Edge Function、Secrets

## 6. 完了条件

1. 初回表示および会場・レース選択後、予想開始前に本命ルーレットが「1・2・3」と表示される。
2. 初期数字が予想結果や買い目として扱われない。
3. STARTは既存の選択・データ準備条件を満たすまで無効のままである。
4. START後の既存ルーレット演出と確定結果が維持される。
5. 会場・レース欄を含む他のUI仕様・見た目に差分がない。
