# トップページ表示調整 基本設計書 v0.1.20

作成日: 2026-10-01 JST
状態: Safari横はみ出し対策まで実装済み。公開前。

関連: [詳細設計](TOP-PAGE-FIX-DETAILED-DESIGN-v0.1.20.md)、[試験仕様](TOP-PAGE-FIX-TEST-SPEC-v0.1.20.md)、[試験成績](TOP-PAGE-FIX-TEST-REPORT-v0.1.20.md)

## 1. 要求

| 項目 | 利用者の希望 | 設計 |
|---|---|---|
| アイコン | タイトル左側、顔を視認できる大きさ | 既存のAIタカシ画像を使用。スマートフォン64px角、幅768px以上80px角を提案 |
| レース選択 | 幅を広げず、閉じた欄は「9R」、開いた一覧は時刻付き | 標準selectを利用。閉じた表示だけ番号にし、optionは「9R　18:52 締切予定」。iOS Safariでの横はみ出しをselect内でクリップ。親幅64% / 最小220px / 最大280pxと均等配分を維持 |
| レース展開 | 初期の例文を削除し、生成前は空欄 | 初期HTMLの例文を削除。生成成功後に展開文を表示 |
| 白い枠の横幅 | コメント欄をルーレット欄の幅に合わせたい | コメント全体を囲む白い枠を左右7pxずつ内側へ寄せ、ルーレットの枠と幅・左右端を一致させる |

## 2. アイコンとタイトル

アイコンはタイトルの左に置き、間隔を12px設ける。画像を縮めて読みにくくしない。狭い画面ではタイトルを2行に折り返し、画像の右側に収める。画像の追加クリック操作は設けない。タイトルで名前を読めるため、画像の代替テキストは空とする。

## 3. レース欄の番号のみ表示（A案）

標準selectによる選択操作を維持する。閉じた表示は未選択なら「レース」、選択後は「9R」のように番号だけとする。開いた一覧は「9R　18:52 締切予定」、締切済みは「9R　締切」。別の時刻欄は設けない。

開閉イベントでoptionを書き換えず、閉じた表示に番号を重ねる。タッチ・キーボード・キャンセル操作はブラウザー標準に任せる。読み上げにはoptionの締切情報を残す。会場変更・締切・日付更新で選択が消えた場合も表示を「レース」へ戻す。欄幅、文字サイズ、選択値、AI処理は変えない。

## 4. 展開欄

ページを開いた直後、JavaScript実行前、取得待ち・取得失敗の場合も例文を表示しない。「レース展開」の見出しは維持し、本文だけ空にする。生成成功時は受信した本文を表示し、選択変更・生成失敗時のクリアは既存の処理に従う。

## 5. 今回の成果物と公開

レース欄の表示だけを今回のA案へ更新する。公開時にはCSS/JSのキャッシュ識別子を更新する。

## 6. 白い枠の幅をそろえる

現行CSSでは、ルーレットを包むgame-heroに左右7pxの内側余白があり、game-panelの外幅は親より14px狭い。コメント全体のcomments-sectionは同じ親幅の100%なので、コメント枠が14px広い。これはCSSから算出した差で、画面の実測値ではない。

ルーレット側の外幅を基準に、コメント枠を左右7pxずつ内側へ寄せる。幅だけでなく左端・右端をそろえる。対象はコメント一覧全体の白い枠であり、コメント投稿ダイアログや各コメントの内部余白は変更対象にしない。

## 7. 対応状況

A案とSafari向け横はみ出し対策を実装し、ローカルWebKit/Edgeで試験済み。公開前。
